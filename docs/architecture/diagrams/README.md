# Rendered architecture diagrams

- Azure deployment: [editable SVG](azure-deployment.svg) and [PNG rendering](azure-deployment.png)
- AWS deployment: [editable SVG](aws-deployment.svg) and [PNG rendering](aws-deployment.png)
- Delivery and Terraform state control plane: [editable SVG](delivery-control-plane.svg) and [PNG rendering](delivery-control-plane.png)

The SVG files are editable, version-controlled diagram source and the rendered output. They reference the official provider icons stored under `icons/`.

Microsoft Azure icons are sourced from the official Azure Architecture Center icon package. AWS icons are sourced from the official AWS Architecture Icons package. The icons are used only for this architecture documentation and training material.

When a service, trust boundary, protocol, identity relationship, policy, or cost-sensitive component changes, update the corresponding SVG and its narrative architecture page in the same change.
